# Simple Icon Integration — Demo Website

A responsive front-end demo built to match the brief: **integrate a set of pre-designed icons into a basic website structure**.

## Features
- Responsive layout for desktop, tablet, and mobile
- Consistent inline SVG icon style
- Icon library with live search
- Light/dark theme toggle
- Accessible navigation, labels, and buttons
- Plain HTML, CSS, and JavaScript; no build tools required

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a modern browser.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `simple-icon-integration`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under the build/deployment section, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After GitHub Pages publishes the site, use the URL it provides as the similar-work link.

## Project scope
This is a front-end demonstration created for the Simple Icon Integration brief. It is not connected to a backend or external service.
